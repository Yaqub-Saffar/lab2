# 02 · SM3 实现与标准对应

| 项 | 值 |
| --- | --- |
| 对应标准 | **GB/T 32905-2016**《信息安全技术 SM3 密码杂凑算法》<br>**GM/T 0004-2012**《SM3 密码杂凑算法》（密标委标准列表第 0004 号） |
| 被测源码 | `third_party/SM2349/src/SM3.c`、`SM3.h`（检测中心发布） |
| 输出 | 256 bit 摘要 |
| 本实验验证方式 | 国标附录 A 向量 + `gmssl sm3` 互验 |

## 2.1 标准 ↔ 代码对应关系

| 标准条款 | 标准要求 | 代码位置 | 代码写法 |
| --- | --- | --- | --- |
| GB/T 32905-2016 §5.1 | 消息分组：512 bit | `SM3.c:261` `SM3_process` | 按 64 字节整块处理，余量进 `md->buf` |
| GB/T 32905-2016 §5.2 | 填充 `1` + 若干 `0` + 长度（64 bit 大端） | `SM3.c:289` `SM3_done` | `md->buf[md->curlen] = 0x80;`（`:298`），随后补 `0` 并写 `len<<3` |
| GB/T 32905-2016 §5.3 | 初始向量 IV | `SM3.c:210` `SM3_init` | `SM3.h:32-39`：`0x7380166f 0x4914b2b9 0x172442d7 0xda8a0600 0xa96f30bc 0x163138aa 0xe38dee4d 0xb0fb0e4e` |
| GB/T 32905-2016 §5.4 | 压缩函数 `CF(V,X)` | `SM3.c:236` `SM3_compress` | 64 轮迭代，轮函数 `FF_j` / `GG_j` |
| GB/T 32905-2016 §5.4 | `FF_j`：0≤j≤15 异或，16≤j≤63 多数 | `SM3.h:44-45` | `SM3_ff0 = a^b^c`；`SM3_ff1 = (a&b)|(a&c)|(b&c)` |
| GB/T 32905-2016 §5.4 | `GG_j`：0≤j≤15 异或，16≤j≤63 选择 | `SM3.h:46-47` | `SM3_gg0 = e^f^g`；`SM3_gg1 = (e&f)|((~e)&g)` |
| GB/T 32905-2016 §5.4 | 消息扩展 `W_j` | `SM3.c:236` 内部 | 68 个字，`W_j'` 异或 `P1`/`P0` 置换 |
| GB/T 32905-2016 §5.4 | 常量 `T_j`：0≤j≤15 `0x79cc4519`，16≤j≤63 `0x7a879d8a` | `SM3.h:30-31` | `SM3_T1` / `SM3_T2` |
| GB/T 32905-2016 §5.4 | 置换 `P0(x)`、`P1(x)` | `SM3.h:42-43` | `P1` 旋转 15、23 位；`P0` 旋转 9、17 位 |
| GB/T 32905-2016 §6 | 输出：截取 V 的前 32 字节，大端 | `SM3.c:335-336` | `memcpy(hash, md->state, 32)` + `BigEndian(...)`（小端 CPU 需转字节序） |
| GB/T 32905-2016 附录 A | 示例： `"abc"` → `66c7f0f4…` | `SM3.c:391`（上游自检） | 上游自检程序内已内置标准向量 |

## 2.2 实测：国标附录 A 向量

```bash
$ ~/exp2/our/bin/drv_sm3 -in_str abc
66C7F0F462EEEDD9D1F2D46BDC10E4E24167C4875CF2F7A2297DA02B8F4BA8E0

$ printf 'abcd%.0s' $(seq 1 16) > /tmp/m64.bin
$ ~/exp2/our/bin/drv_sm3 -in /tmp/m64.bin
DEBE9FF92275B8A138604889C18E5A4D6FDB70E5387E5765293DCBA39C0C5732
```

两个值与 GB/T 32905-2016 附录 A 的示例值逐字相同。

## 2.3 实测：与 GmSSL 互验

`scripts/verify_all.sh` 取 1000 字节随机数据，两边摘要必须完全一致：

```bash
$ head -c 1000 /dev/urandom > /tmp/rand.bin
$ gmssl sm3 -in /tmp/rand.bin
$ ~/exp2/our/bin/drv_sm3 -in /tmp/rand.bin
```

验证脚本第 3 项 `SM3 vs gmssl sm3 (1000 random bytes)` → **PASS**。

> 坑：GmSSL 的 `sm3` 子命令在终端里会等 tty 输入，用脚本调用时必须重定向
> `< /dev/null`，否则整个验证脚本会挂住。

## 2.4 结论

- 检测中心的 SM3 实现与 GB/T 32905-2016 在**填充规则、IV、轮函数、置换、常量、字节序**
  六个方面逐条对应，无偏差；
- 附录 A 标准向量、GmSSL 互验全部通过；
- 上游自检程序 `./SM3` 退出码 0。
