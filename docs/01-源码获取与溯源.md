# 01 · 源码获取与溯源

> 目标：证明「调试运行商用密码检测中心提供的源代码」这句话站得住脚——
> 本实验编译的每一行代码，都能追溯回官方发布物。

## 1.2 关键发现：官方包里没有 `.c`/`.h`，只有 PDF

三个压缩包解开后的完整内容（实测）：

```
SM2算法源代码/
├── 免责声明.pdf
├── 加解密/{SM2_加解密_c文件.pdf, SM2_加解密_h文件.pdf, SM2_加解密_kdf.pdf}
├── 密钥协商/{SM2_KeyExchange_c文件.pdf, ...}
└── 签名验签/{SM2_签名验签_c文件.pdf, SM2_签名验签_h文件.pdf, SM2_签名验签_kdf.pdf}
SM3算法源代码/{SM3_c文件.pdf, SM3_h文件.pdf, 免责声明.pdf}
SM4算法源代码/{SM4_c文件.pdf, SM4_h文件.pdf, 免责声明.pdf}
```

也就是说，**官方以 PDF 清单的形式发布源码**，无法直接编译。
（宿主的 `tar.exe` 虽是 bsdtar，仍能解开 RAR3 包，本实验用它解包。）

## 1.3 把 PDF 还原成文本

`scripts/pdf_text.py`（纯 `pypdf`，无需额外环境）把 16 个 PDF 全部抽成文本，
结果存 `artifacts/official/pdf-text/`。

## 1.4 镜像源码逐行回查官方 PDF

可编译的源码来自官方镜像 <https://github.com/Arkq/SM2349>（commit `3364e2a`）。
镜像自己的 commit 历史第 3 条标题就是 **"Add source files extracted from PDFs"**——
即镜像源码就是官方 PDF 的抽取结果。

但本实验不靠这句话背书，而是做了**独立复核**：
`scripts/compare_pdf_code.py` 把镜像 `.c` 逐行（去缩进、去注释、去掉过短的行）
去官方 PDF 文本里做子串匹配：

```
SM3.c            vs SM3_c文件.txt             : 201/204 code lines found in the official PDF (98.5%)
SM4.c            vs SM4_c文件.txt             :  89/ 92 code lines found in the official PDF (96.7%)
SM2_sv.c         vs SM2_签名验签_c文件.txt      : 304/326 code lines found in the official PDF (93.3%)
SM2_ENC.c        vs SM2_加解密_c文件.txt        : 264/281 code lines found in the official PDF (94.0%)
SM2_KEY_EX.c     vs SM2_KeyExchange_c文件.txt   : 495/517 code lines found in the official PDF (95.7%)
total: 1353/1420 (95.3%)
```

**结论：镜像中 1420 行有效代码，有 1353 行能在官方 PDF 原文中逐字命中（95.3%）。**
未命中的少数行是 PDF 抽取时换页/断字造成的（文本已存证，可自行复核），
不影响「这份源码就是检测中心发布的源码」这一结论。

## 1.6 入库与授权

- 仓库内 `third_party/SM2349/` 只放 `src/`、`Makefile`、上游 README 与 `NOTICE.md`；
- **MIRACL 库不入库**（独立许可、体积大），按 `docs/00` 的步骤在虚机内单独获取；
- 上游 README 的授权声明原文保留在 `third_party/SM2349/UPSTREAM-README.md`：

  > Every source code in this repository can be used for academic, non-profit
  > making or non-commercial use only. All implementation are based on MIRACL
  > Cryptographic SDK, which also requires a proper license …

  即仅限学术、非营利、非商业用途。本实验为课程教学验证，符合该范围；
  本人新增的验证程序在仓库根 `tools/` 下，与上游代码分开，未改动上游任何一行。

## 1.7 复现命令

```powershell
# 1) 下载官方包（Windows 自带 tar 能解 RAR3）
Invoke-WebRequest -Uri "https://www.scctc.org.cn/xzzx/sfydm/ydmxz/829b3a539f374a9dba35b56af7b55f5e/b49339a51a4745599fd6aa06a3ddddcf.rar" -OutFile SM2.rar

# 2) PDF -> 文本
py scripts/pdf_text.py artifacts/official/extracted/SM3算法源代码/SM3_c文件.pdf artifacts/official/pdf-text/SM3_c文件.txt

# 3) 逐行回查
py scripts/compare_pdf_code.py artifacts/official/pdf-text third_party/SM2349
```
